# Changed in the port to zapret2: the strategy is rewritten as winws2 options (Lua desync instead of
# --dpi-desync); Discord voice and STUN are caught by their ports in --wf-udp-out, as Flowseal does,
# not by WinDivert filter files (--wf-raw-part).
# Mapping: fooling ts -> tcp_ts=-600000:tcp_ts_up (nfqws1's default ts increment,
# timestamp option first as nfqws1 sent it), on fakes only, as in nfqws1;
# --dpi-desync-repeats -> repeats= on the fakes; hostfakesplit applies fooling to its fakes only, host=X kept;
# each --dpi-desync-fake-* file -> its own fake call, in the .bat's order, for its payload type only;
# the first QUIC profile has no --filter-udp, as in the .bat (QUIC on any intercepted UDP port);
# voice: --filter-l7=discord,stun,unknown kept, the -unknown-udp fakes go to the unknown payload;
# the games TCP profile has no --dpi-desync-fake-unknown: nfqws1 then sent its default unknown fake,
# 256 zero bytes -> blob zero_256 made in --lua-init;
# --ip-id=zero -> ip_id=zero on every call of the profile (winws2 has no --ip-id);
# --dpi-desync-cutoff=nN -> --out-range=-n<N-1> (nfqws1 acts while the packet number is below N);
# --dpi-desync-any-protocol -> --payload=known,unknown and payload= on the calls (TCP), payload=all (UDP);
# TCP profiles without a cutoff get --out-range=-d10 (zapret2's convention: the hello comes first).
# The ipset-all TCP profile has no --filter-l7, as in the .bat: other traffic to those addresses stays
# in it with no action instead of falling through to the games profile (nfqws1 profile semantics).
--wf-tcp-out=80,443,2053,2083,2087,2096,8443,%GameFilterTCP%
--wf-udp-out=443,19294-19344,50000-65535,%GameFilterUDP%
--lua-init=@"%LUA%zapret-lib.lua" --lua-init=@"%LUA%zapret-antidpi.lua"
--lua-init="zero_256 = string.rep(string.char(0), 256)"
--blob=quic_google:@"%BIN%quic_initial_www_google_com.bin"
--blob=quic_4pda:@"%BIN%quic_initial_4pda_to.bin"
--blob=tls_google:@"%BIN%tls_clienthello_www_google_com.bin"
--blob=tls_max:@"%BIN%tls_clienthello_max_ru.bin"
--blob=stun2:@"%BIN%stun2.bin"
--blob=discord_udp:@"%BIN%ACTIVE_DISCORD_UDP.bin"
--blob=game_udp:@"%BIN%ACTIVE_GAME_UDP.bin"

--payload=quic_initial --lua-desync=fake:blob=quic_google:repeats=11

--lua-desync=fake:blob=discord_udp:repeats=4:payload=all
--new

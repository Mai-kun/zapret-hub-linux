# Changed in the port to zapret2: the strategy is rewritten as winws2 options (Lua desync instead of
# --dpi-desync); Discord voice and STUN are caught by their ports in --wf-udp-out, as Flowseal does,
# not by WinDivert filter files (--wf-raw-part).
# Mapping: fooling ts -> tcp_ts=-600000:tcp_ts_up (nfqws1's default ts increment,
# timestamp option first as nfqws1 sent it), on fakes only, as in nfqws1;
# --dpi-desync-repeats -> repeats= on the fakes;
# each --dpi-desync-fake-tls/-http/-unknown file -> its own fake call, in the .bat's order;
# the Google profile is hostfakesplit alone, as in the .bat: host=X kept, fooling on its fakes, no repeats;
# --ip-id=zero -> ip_id=zero on every call of the profile (winws2 has no --ip-id);
# --dpi-desync-cutoff=nN -> --out-range=-n<N-1> (nfqws1 acts while the packet number is below N);
# --dpi-desync-any-protocol -> --payload=known,unknown and payload= on the calls (TCP), payload=all (UDP);
# TCP profiles without a cutoff get --out-range=-d10 (zapret2's convention: the hello comes first).
# The ipset-all TCP profile has no --filter-l7, as in the .bat: other traffic to those addresses stays
# in it with no action instead of falling through to the games profile (nfqws1 profile semantics).
--wf-tcp-out=80,443,2053,2083,2087,2096,8443,%GameFilterTCP%
--wf-udp-out=443,19294-19344,50000-65535,%GameFilterUDP%

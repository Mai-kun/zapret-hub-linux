# Zapret Hub — стратегии Flowseal на zapret2 (подпроект 8)

Дата: 2026-10-17. Основа: спецификация zapret2 (подпроект 5), каркаса (раздел 1, очередь). Делается до
диагностики (`2026-10-17-zapret-hub-diag-design.md`): ей нужен полный набор приёмов zapret2 для circular.

## 1. Зачем

Сейчас у zapret2 в хабе две встроенные стратегии (`general`, `general-sni`, по примеру bol-van), а у
Flowseal — 21 стратегия `general*.bat`, проверенная на Discord, YouTube и играх. Пользователь хочет,
чтобы при первом запуске хаба на zapret2 были **все стратегии Flowseal**, без ручного переноса.

Решения пользователя (2026-10-17):
- Переносим все стратегии Flowseal на zapret2 и кладём в репозиторий.
- Копии **фиксированные**: снимок текущего Flowseal, обновляем их мы новым выпуском хаба; хаб сам на
  лету не переводит.
- Копия принимается после **теста хаба через CLI** на Discord, YouTube и DbD пользователя — не хуже
  оригинала Flowseal. Тест временно переключает обход — допустимо.
- Не вышло сделать не хуже — копия всё равно входит в набор, **без пометок** в интерфейсе.
- Тест хаба проверяет только HTTPS (сайты профилей Discord, YouTube, DbD), не голос и не игровой UDP:
  принимаем по тесту, а **голос Discord вручную — у пяти лучших копий** по рейтингу (пользователь в
  голосовом канале, агент переключает).
- Встроенные копии **не входят в прогон тестов по умолчанию** (без имён и в выборе окна по умолчанию):
  их выбирают вручную; «применить лучшую» не меняет движок незаметно.

## 2. Объём

Входят все `general*.bat` Flowseal 1.10.3 (`E:\Zapret`), кроме своих стратегий хаба
(`general (HUB …).bat`): `general`, `general (ALT)`, `(ALT2)`…`(ALT13)`, `(EXP)`, `(FAKE TLS AUTO)`,
`(FAKE TLS AUTO ALT)`…`(ALT3)`, `(SIMPLE FAKE)`, `(SIMPLE FAKE ALT)`, `(SIMPLE FAKE ALT2)` (по папке — 22 файла; точный список — по папке при переносе). `service.bat`, `discord-udp-proxy.bat` — не стратегии.

Не входят: автоматический перевод `.bat` в хабе; Linux; изменения логики применения и тестов.

## 3. Как устроено

- Текст каждой копии — файл `crates/zapret2/src/builtin/flowseal/<имя>.txt`, встроенный в exe
  (`include_str!`), в реестре `BUILTIN` рядом с `general` и `general-sni`. Только для чтения, как они:
  изменить — через копию (клон).
- **Имена:** `zapret2:<имя Flowseal>` — `zapret2:general (ALT5)`, `zapret2:general (FAKE TLS AUTO)`.
  Исключение: `general.bat` Flowseal → `zapret2:general (Flowseal)`, потому что `zapret2:general` уже
  занят встроенной стратегией bol-van (решение исполнителя).
- Шапка каждого файла — комментарии: источник (`Flowseal/zapret-discord-youtube 1.10.3, general (ALT5).bat,
  MIT License, Copyright (c) Flowseal`), что изменено при переносе и, если копия хуже оригинала на
  тесте, — короткая строка об этом (в файле, не в интерфейсе).
- Списки, фейки и игровой фильтр — из папки Flowseal через уже поддержанные подстановки (`%LISTS%`,
  `%BIN%` — это `bin` Flowseal, `%GameFilter…%`); свои файлы zapret2 — `%FILES%`. Копии ссылаются на
  имена файлов Flowseal 1.10.3; нет файла — ошибка запуска сама это покажет.
- **Перевод параметров winws → winws2:** каждый профиль (`--new`) переводится в профиль zapret2:
  `--filter-*`, списки и `--wf-*` — как есть (`--wf-tcp/udp` → `--wf-tcp-out/udp-out`, плюс
  голос и STUN ловятся **по портам** в `--wf-udp-out`, как во встроенной `general`, а не через
  `--wf-raw-part` из `init.d` — его нет в раскладках zapret-win-bundle и `bin`); `--dpi-desync=…` и его
  `--dpi-desync-*` — в цепочку `--payload=… --lua-desync=…` по разделу руководства zapret2 о переходе с
  nfqws1 (`multidisorder_legacy`, если нужна точная совместимость). Образец — `zapret2:ALT11` из папки
  стратегий пользователя (ручной перенос `general (ALT11)`, работает у пользователя).
- Имена со скобками не проходят `validate_name` своих стратегий: встроенные обходят это (константа),
  а копия встроенной получает имя без скобок — `ALT5 copy` для `general (ALT5)` (сейчас окно
  предлагает `general (ALT5) copy`, которое отклоняется).
- Тест `crates/zapret2/tests/strategies.rs` (1–3 встроенные, в шапке «bol-van» и «MIT») меняется под
  новый набор: в шапке — источник (bol-van или Flowseal) и «MIT».
- Тесты по умолчанию: без имён прогон и выбор окна берут стратегии текущего движка и свои, но не
  встроенные копии Flowseal.

## 4. Приёмка

Для каждой копии — прогон через CLI работающего хаба (стандартный набор: Discord, YouTube, DbD):

```
zapret-hub-cli tests run --wait "general (ALT5)" "zapret2:general (ALT5)"
```

- «Не хуже» = у копии не меньше `ok` по каждому из трёх профилей рейтинга (`score.discord/youtube/dbd`)
  и медиана задержки профиля не больше чем на 20 % выше (профиль с `total` 0 или без медианы
  сравнивается только по `ok`); мелкий разброс — повторный прогон пары (`--repeats 2`).
- Копия, которая не запускается или не проходит статическую проверку, в набор не входит — это
  поломка, не «хуже».
- Голос Discord вручную у пяти лучших копий: пользователь в голосовом канале, агент применяет копию,
  пользователь говорит «работает / нет»; итог — в таблице приёмки.
- Хуже → до трёх попыток поправить перевод (другой вариант приёма, `multidisorder_legacy`, порядок
  инструкций); не вышло — копия входит как есть, строка в шапке файла и в таблице приёмки.
- Таблица приёмки (стратегия, `ok` и медианы оригинала и копии по профилям, вердикт, что правилось) —
  `docs/flowseal-zapret2.md`; номера прогонов — ссылки на `tests list`.
- Прогоны идут один за другим; каждый сам снимает и возвращает состояние (тестер). Перед серией и после
  неё — `status` и `quick-check`: стратегия пользователя та же, проверка проходит.
- Перевод и прогоны делает агент; права администратора — у работающего хаба (CLI их не требует).

## 6. Риски

- **Не всё переводится один к одному.** Часть приёмов winws1 в zapret2 работает иначе (multidisorder
  по reasm). Смягчение — `multidisorder_legacy` и проверка тестом.
- **Тест — снимок одного вечера у одного провайдера.** Разброс между прогонами возможен; повтор пары при
  пограничном результате.
- **Тест не трогает UDP**: голос проверяется вручную у пяти лучших, игровой UDP DbD — нет.
- **Время:** 22 пары × несколько минут — около часа переключений обхода у пользователя.

# Zapret Hub

Приложение в трее для [Flowseal zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube):
выбирает и переключает стратегии, тестирует их и ставит лучшую, делает всё, что умеет `service.bat`.

## Что умеет

- **Обзор:** служба, стратегия, быстрая проверка, версия Flowseal, прокси SOCKS5, лучшая стратегия последнего теста.
- **Стратегии:** все `general*.bat` в порядке меню `service.bat`, аргументы по блокам, применение в один клик.
  Свои стратегии — копия оригинальной с редактором блоков и проверкой `winws --dry-run`.
- **Тесты:** стандартный набор `test zapret.ps1` (HTTP, TLS 1.2, TLS 1.3, пинг) и набор DPI 16–20. Живой прогресс,
  рейтинг, история, копирование результатов в формате `test zapret.ps1`.
- **Zapret:** игровой фильтр, ipset, фейки, свои списки, обновление ipset и hosts, системные проверки `service.bat`,
  очистка кэша Discord, удаление службы.
- Хаб держит в `list-general-user.txt` свой набор доменов (AWS, X/Twitter, Cloudflare, серверы и сайт DbD, NuGet):
  недостающие дописываются при каждом запуске; набор — `crates/zapret/src/default-general-user.txt`.
- **Трей:** цвет иконки показывает состояние, меню переключает на стратегии из первой пятёрки рейтинга, быстрая
  проверка раз в 30 минут, уведомления Windows.
- **Командная строка:** `zapret-hub-cli.exe` для ИИ-агентов и скриптов — те же действия, что в окне, кроме смены папок zapret и zapret2, вывод в JSON.
  Включается в настройках.
- **zapret2:** стратегии [bol-van/zapret2](https://github.com/bol-van/zapret2) (`winws2.exe`, стратегии на Lua)
  рядом со стратегиями Flowseal: те же тесты и рейтинг, служба `zapret2` в один клик, свои стратегии в текстовом
  редакторе.

## Как выбирается лучшая стратегия

Стандартный набор: выше та, у которой меньше неудачных проверок; при равенстве — меньше медианная задержка
удачных проверок (HTTP, TLS 1.2, TLS 1.3). Набор DPI: выше та, у которой меньше проверок с признаком
блокировки, затем меньше неудачных. Дальше — порядок меню `service.bat`. ICMP-пинг показан отдельным
столбцом и на порядок не влияет. Стратегия, которая не запустилась, — в конце.

## Что нужно

- Windows 10 1803 или новее, либо Windows 11, x64. `curl.exe` входит в Windows начиная с 1803.
- Права администратора: приложение управляет службой zapret и WinDivert.
- WebView2 Runtime. В Windows 10 и 11 он обычно уже есть; если нет, приложение покажет ссылку на загрузку.
- Папка Flowseal zapret-discord-youtube (проверено на 1.10.3), распакованный релиз bol-van/zapret2 или обе.
  Их можно скачать кнопкой «Скачать последний релиз…» в мастере и в «Настройках» (раздел «Скачать движок» ниже).

## Установка и запуск

Архив `zapret-hub-<версия>.zip` — на странице [релизов](https://github.com/brano-san/zapret-hub/releases).

1. Распакуйте архив в отдельную папку, например `C:\Tools\ZapretHub`. Настройки и данные лежат рядом с exe.
   С автозапуском берите папку, куда без прав администратора не записать, например внутри `C:\Program Files\`:
   задача автозапуска запускает exe с наивысшими правами без запроса UAC, а exe в папке, открытой для записи
   (как `C:\Tools\…`), может подменить любая программа.
2. Запустите `zapret-hub.exe` и подтвердите запрос UAC.
3. Мастер первого запуска на первом шаге спрашивает обе папки: zapret (найдёт её по установленной службе или
   запущенному `winws.exe` или даст выбрать вручную) и zapret2; любую можно скачать с GitHub. Хватит одной из них. Затем предложит прокси
   SOCKS5, если тот сейчас отвечает, и спросит про автозапуск.

Крестик прячет окно в трей, выход — «Выход» в меню трея. Повторный запуск exe открывает уже работающую копию.

## Где данные

Всё рядом с exe:

- `zapret-hub.toml` — настройки;
- `data\strategies\` — свои стратегии;
- `<папка zapret2>\strategies\` — свои стратегии zapret2, по файлу `<имя>.txt`: лежат у движка и переживают обновление приложения, старые из `data\zapret2` переносятся при первом запуске;
- `data\routes.toml` — правила маршрутизации через SOCKS5;
- `data\tests\` — результаты тестов, `data\cache\` — набор DPI;
- `data\logs\ГГГГ-ММ-ДД.log` — журнал: каждая команда (`sc`, `net`, `curl.exe`, `winws.exe` и другие) с кодом выхода
  и полным выводом;
- `data\state\pending.json` — снимок на время изменяющей операции. Если приложение закрылось посреди неё, при
  следующем запуске оно вернёт службы zapret и zapret2, ipset, игровой фильтр, winws и winws2 как было и скажет об этом;
- `data\webview\` — данные окна.

## Что приложение меняет в системе

- Службу `zapret` и имя стратегии в реестре — так же, как `service.bat`. `service.bat` и `test zapret.ps1`
  продолжают работать.
- Службу `zapret2`, когда применена стратегия zapret2, и имя стратегии в реестре на её ключе. Установлена одна
  служба из двух: применение стратегии одного движка удаляет службу другого.
- Файлы в папке zapret: флаги и списки в форматах `service.bat`; свои стратегии — файлы
  `general (HUB <имя>).bat`, их видно и в меню `service.bat`.
- `hosts` — только по кнопке «Обновить hosts» и после подтверждения: блок между строками `# zapret-hub begin`
  и `# zapret-hub end`.
- Задачу Планировщика «Zapret Hub», если включён автозапуск.
- Ключ `HKCU\Software\Classes\AppUserModelId\ZapretHub` — имя приложения в уведомлениях.
- Именованный канал `\\.\pipe\zapret-hub-cli`, пока приложение работает. Команды через него выполняются, только
  если в настройках включено «Управление из командной строки».
- Глобальную настройку TCP: при каждой установке службы, как `service.bat`, и по кнопке системной проверки —
  `netsh interface tcp set global timestamps=enabled`. Она действует на всю систему и остаётся после удаления
  приложения; если до этого она была выключена (так по умолчанию в Windows), вернуть:
  `netsh interface tcp set global timestamps=disabled`.
- Фейки на вкладке Zapret заменяют `bin\ACTIVE_DISCORD_UDP.bin` и `bin\ACTIVE_GAME_UDP.bin` копией выбранного
  файла; обновление ipset оставляет прежний список в `lists\ipset-all.txt.hub-prev`.
- Перед записью `hosts` его прежний текст сохраняется рядом, в `hosts.zapret-hub.bak`.
- Кнопки системных проверок, как `service.bat`, удаляют службы GoodbyeDPI, discordfix_zapret, winws1, winws2,
  WinDivert и WinDivert14, а также службу `zapret2`, если рядом установлена `zapret`.
- Дескрипторы WinDivert из папки движка, пока маршрутизация включена: драйвер движка, своего хаб ничего не
  ставит. Закрытие хаба закрывает дескрипторы, и трафик идёт как был.
- Очистка кэша Discord закрывает Discord и удаляет его папки `Cache`, `Code Cache` и `GPUCache`.

## Тесты стратегий

На время прогона служба zapret или zapret2 останавливается, а winws или winws2 по очереди запускается с каждой
выбранной стратегией; после прогона служба, ipset и winws возвращаются как были. Стандартный набор — около
15 секунд на стратегию, все 22 стратегии Flowseal 1.10.3 — около 6 минут. Прогон можно отменить; закрытие окна
его не прерывает.

## Скачать движок

В мастере (в каждом из двух блоков) и в «Настройках» (под папкой zapret и под папкой zapret2) есть кнопка
«Скачать последний релиз…». Выберите, куда скачать (по умолчанию — папка над папкой приложения, а если в её пути
есть пробелы или кириллица — корень системного диска), и нажмите «Скачать».

- Источник только один на движок: последний релиз
  [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube/releases) (архив
  `zapret-discord-youtube-<версия>.zip`) или [bol-van/zapret2](https://github.com/bol-van/zapret2/releases)
  (`zapret2-<версия>.zip`). Адрес берётся из GitHub API, качает системный `curl.exe`; если напрямую не вышло, —
  через прокси из настроек. Ход загрузки виден, её можно отменить.
- Релиз распаковывается в новую папку `<куда>\zapret-discord-youtube-<версия>` или `<куда>\zapret2-<версия>`.
  Если такая папка уже есть и не пустая, загрузка отказывается.
- Проверка: у zapret2 каждый файл `binaries\windows-x86_64\*` и `lua\*` сверяется с `sha256sum.txt` релиза; при
  несовпадении папка удаляется. У Flowseal файла с суммами нет: приложение показывает SHA-256 архива (он же в
  журнале) и проверяет, что на месте `service.bat`, `bin\winws.exe`, `bin\WinDivert64.sys` и `lists\`.
- Защитник Windows часто удаляет эти архивы и `winws`. Тогда приложение скажет об этом и оставит пустую папку:
  добавьте её в исключения (Безопасность Windows → Защита от вирусов и угроз → Управление настройками →
  Исключения) и скачайте снова. Само приложение исключений не добавляет.
- Скачанная папка подставляется в поле и проверяется; сохраняет её, как и выбранную вручную, «Далее» в мастере
  или «Сохранить» в настройках. Из `zapret-hub-cli` скачать нельзя.

## zapret2

[bol-van/zapret2](https://github.com/bol-van/zapret2) — следующий движок автора zapret: `winws2.exe` и
стратегии на Lua. Скачайте релиз со [страницы релизов](https://github.com/bol-van/zapret2/releases), распакуйте
в папку без кириллицы в пути (например `D:\zapret2`) и укажите её в «Настройках» → «Папка zapret2». Подходит и
zapret-win-bundle. Приложение проверит файлы и покажет версию движка или ошибку, если `lua\` не подходит к
движку.

- В списке стратегий после стратегий Flowseal появятся встроенные стратегии zapret2:
  - `zapret2:general` и `zapret2:general-sni` — по примеру из документации zapret2 (bol-van);
  - 22 копии стратегий Flowseal 1.10.3, перенесённые на `winws2`: `zapret2:general (ALT5)`,
    `zapret2:general (FAKE TLS AUTO)` и т.д.; `general.bat` Flowseal — `zapret2:general (Flowseal)`. Копии
    фиксированные (обновляются новым выпуском хаба), в шапке каждой — источник (MIT, Flowseal) и что
    изменено при переносе. В прогон тестов по умолчанию копии не входят — выбирайте их вручную. Клон копии
    получает имя без скобок: `ALT5 copy`.
  Встроенные собраны на списках и фейках Flowseal; подберите лучшую тестом.
- Свои стратегии — текст аргументов `winws2` в редакторе: «Клонировать» у встроенной, затем «Проверить» и
  «Сохранить». Проверка — статическая, `winws2 --dry-run` и `winws2 --intercept=0`.
- Списки, свои списки, режим ipset, фейки и игровой фильтр общие: стратегии zapret2 берут их из папки Flowseal
  (`%LISTS%`, `%BIN%`, `%GameFilter%`). Сама папка Flowseal необязательна: без неё работают стратегии zapret2,
  служба `zapret2` и тесты, а настройки и стратегии Flowseal скрыты. Но встроенные стратегии zapret2 используют
  списки Flowseal и без неё не запускаются (ошибка «the strategy uses %LISTS%»): начните со своей стратегии из
  шаблона.
- **circular** — оркестратор zapret2, который перебирает варианты обхода отдельно для каждого сайта: после
  нескольких неудач (`fails`, по умолчанию 3; неудача — ретрансмиссии, RST или редирект от DPI) переходит к
  следующему варианту и запоминает его. Карточка стратегии показывает circular-профили по-человечески:
  фильтр, `fails`/`retrans` и пронумерованные варианты («1: fake tls_google ×8 + multisplit 1 seqovl»,
  «2: multidisorder midsld», финальный отмечен). В редакторе кнопка «Circular…» открывает конструктор:
  выберите профиль (его инстансы станут вариантом 1) или новый (TCP-порты, протокол, список), добавляйте,
  переставляйте и удаляйте варианты (готовые: fake TLS google, fake stun2, multisplit seqovl, multidisorder
  midsld, fakedsplit — или свой текст), задайте `fails`/`retrans` и финальный вариант, затем «Записать в
  текст». Конструктор пишет `--out-range=-s34228`, `--in-range=-s5556 --lua-desync=circular`,
  `--in-range=x` и метки `strategy=N`, а недостающие блобы `tls_google`/`stun2` добавляет в глобальную
  часть; главным остаётся текст. Статическая проверка не пропустит дыры в номерах `strategy=`, `strategy=`
  без circular и circular без вариантов, а без `--in-range` перед circular предупредит.
- «Сделать circular из стратегий…» (кнопка над списком) объединяет 2–5 стратегий zapret2: профили с
  одинаковым фильтром, которые есть во всех и различаются инстансами, становятся circular с вариантом на
  каждую стратегию в порядке выбора. Остальное берётся из первой. Предпросмотр объясняет каждый профиль
  (UDP-профили не объединяются: circular считает неудачи по TCP), затем текст открывается в редакторе для
  проверки и сохранения. ALT11 и ALT11 plus отличаются только профилем игровых сервисов, так что circular из
  них не получится — нужны стратегии с разными инстансами.
- Папку zapret2, как и папку Flowseal, меняют только в окне: `zapret-hub-cli` её не меняет.
- «Применить» на стратегии zapret2 ставит службу `zapret2` и удаляет службу `zapret`; стратегия Flowseal —
  наоборот. Прогон тестов может смешивать стратегии обоих движков.
- `service.bat` и `test zapret.ps1` о zapret2 не знают. Если `service.bat` поставит `zapret` рядом с `zapret2`,
  системная проверка «Другие обходы блокировок» это покажет; следующее «Применить» наведёт порядок.

## Маршрутизация через SOCKS5

Выбранный трафик идёт через локальный SOCKS5-прокси прямо из процесса хаба: без TUN и без окна PowerShell.
UDP — через `UDP ASSOCIATE`, TCP — через `CONNECT`; цель правила — подсеть IPv4, домен или программа. Это замена
`E:\Zapret\utils\discord-udp-proxy.ps1`: на время работы маршрутизации этот скрипт нужно закрыть.

Как включить:

1. «Настройки» → адрес SOCKS5, например `127.0.0.1:2080`. Прокси должен принимать UDP: в NekoBox это mixed
   inbound. Авторизация не поддерживается. Прокси должен быть на этом компьютере (`127.x.x.x`): с адресом в
   локальной сети маршрутизация не включается и пишет почему.
2. Вкладка «Маршруты» → «Добавить из профиля» → «Discord голос» (UDP, голос), «Discord целиком» (UDP и TCP
   по доменам `discord.com`, `discord.gg`, `discordapp.com`, `discordapp.net`, `discord.media`) или
   «Dead by Daylight» (UDP и TCP, программа `DeadByDaylight-Win64-Shipping.exe` и домен `bhvrdbd.com`).
3. Переключатель «Маршрутизация» (или пункт «Маршрутизация: вкл/выкл» в меню трея, или `zapret-hub-cli router on`). Флаг
   `router_enabled` сохраняется: при следующем запуске маршрутизация включится сама.

Правила лежат в `data\routes.toml`. Файл можно править руками (Блокнот, BOM и CRLF читаются): хаб проверяет его
время записи раз в 2 с и перечитывает при изменении. Битый файл не стирается и не применяется: работающие
правила остаются прежними, а вкладка показывает ошибку с номером строки.

```toml
[[rule]]
name = "Discord целиком"
enabled = true
protocol = "both"                        # "tcp" | "udp" | "both"
ports = []                               # пусто или нет поля = все порты; иначе ["443", "50000-65535"]
ips = ["104.29.0.0/16"]                  # IPv4 или a.b.c.d/n
domains = ["discord.com", "discord.gg"]  # домен и все его поддомены
apps = ["Discord.exe"]                   # имя .exe или полный путь в одинарных кавычках: 'C:\Games\game.exe'
```

- Имя: 1–40 символов (латиница, кириллица, цифры, пробел, `-_.`), начинается с буквы или цифры, уникально без учёта регистра.
- `protocol` обязателен: `"tcp"`, `"udp"` или `"both"`. Хотя бы одна цель: `ips`, `domains` или `apps`.
- Порты: `1–65535` или диапазон `a-b`, `a ≤ b`.
- Домен: без схемы и пути, не меньше двух меток из латиницы, цифр и `-`, регистр не важен.
- `apps`: имя файла (без `\`, `/` и `:*?"<>|`) или абсолютный путь (`C:\…`, `\\server\share\…`), в обоих случаях
  оканчивается на `.exe` без учёта регистра; иначе ошибка «is not a program» с номером строки.
- Соединение или поток идёт в прокси, если совпало хотя бы одно включённое правило: протокол, порт и цель.
- Подсетей в фильтре WinDivert не больше 64 диапазонов: сверх этого ближайшие диапазоны сливаются, и фильтр шире
  правил. Хаб сверяет совпадение сам и лишнее отправляет без изменений, но через хаб идёт больше пакетов. Предел:
  слитый диапазон правила без портов (например, «Discord целиком») может направить через хаб весь трафик к
  широкому диапазону: нагрузка на процессор и задержка при долгой работе.
  Если фильтр не влез и после слияний, ошибка правил — «too many rules for the capture filter»: выключите или
  сузьте часть правил.
- Multicast, broadcast и DHCP (с адреса `0.0.0.0`) в прокси не уходят никогда.

Домены и TCP:

- Домены узнаются из ответов DNS: хаб подсматривает их по UDP-порту 53 и запоминает адреса домена на срок
  TTL, но не меньше 5 минут и не больше суток. Если браузер или программа использует «безопасный DNS» (DNS по HTTPS) или DNS по
  TLS, ответов хаб не видит: выключите «безопасный DNS» в браузере или добавьте подсети в `ips`. То же при зашифрованном DNS в самой Windows («Параметры» → «Сеть и Интернет» → свойства адаптера → «Шифрование DNS»): системные запросы идут по HTTPS, и правила по доменам не срабатывают ни для одной программы; хаб видит это по реестру и предупреждает на вкладке «Маршруты».
- TCP перенаправляется в локальный приёмник хаба на `0.0.0.0` (один на сеанс маршрутизации), а тот делает
  `CONNECT` к прокси. При первом включении Windows может спросить про брандмауэр для `zapret-hub.exe`:
  разрешите доступ. Хаб правил брандмауэра не добавляет и не меняет. Если соединение к приёмнику заблокировано,
  через 2 с адрес на 60 с уходит напрямую, а во вкладке «Потоки» строка «напрямую: брандмауэр Windows не
  пропустил соединение к хабу».
- Соединения, открытые до включения маршрутизации или до появления правила (например, уже запущенный Discord),
  идут как были; через прокси пойдут новые соединения, то есть после перезапуска программы.
- SYN, отправленный раньше, чем хаб разобрал ответ DNS с этим адресом, может уйти напрямую.
- Поток UDP, начавшийся в момент смены фильтра перехвата, может посреди потока перейти с прямого пути на прокси
  (QUIC при этом откатывается на TCP).
- Адрес помнит последний домен, под которым его видел DNS: `CONNECT` и заголовок UDP к прокси несут этот домен.
- Прокси отказал в `CONNECT` или не ответил за 3 с: клиент получает RST, а адрес на 60 с идёт напрямую. Когда
  прокси вернулся после недоступности, эти пометки снимаются.
- Пауза (тест стратегий, смена движка) и выключение маршрутизации обрывают перенаправленные TCP-соединения: программа
  переподключается. Полузакрытое соединение живёт, пока не пройдёт 120 с без пакетов.
- Правило выключено или запись DNS истекла посреди соединения: открытое соединение остаётся как было. Адрес
  живого потока UDP не истекает, пока поток жив.
- Таблица «адрес → домен» живёт в хабе и переживает паузы.

Программы:

- Совпадение без учёта регистра: элемент с `\` — полный путь к exe, иначе — имя файла exe. Правило с
  `apps` совпадает и по `ips`/`domains`: достаточно любой цели.
- TCP решается на первом SYN соединения, UDP — на первом пакете потока. Программа, запущенная до включения
  маршрутизации (например, игра посреди матча), узнаётся по таблицам Windows.
- Пока запущена программа из UDP-правила, через хаб идёт весь исходящий UDP на портах правила (чужие пакеты
  уходят дальше без изменений), поэтому лучше указать порты. Пока программа не запущена, UDP не
  перехватывается; TCP — только первые SYN.
- Браузер в `apps` заставляет хаб пересобирать фильтр на каждый новый адрес назначения.
- Первые пакеты UDP программы, чей первый сокет — UDP и открыт раньше, чем пересобрался фильтр, могут уйти
  напрямую.
- Потоки без правила, пойманные ради правил по программе, видны во вкладке «Потоки» при «все» (не больше
  500 строк, в итоги не входят).

Что важно знать:

- Прокси не отвечает две проверки подряд (проверка раз в 10 с) — новые потоки и соединения идут напрямую, в шапке
  вкладки и в подсказке значка трея «прокси недоступен, трафик идёт напрямую», на значке — красная точка. Когда
  прокси вернулся, через него снова идут новые потоки и те, что ушли напрямую из-за его отказа (звонок продолжается
  через прокси).
- На время прогона тестов стратегий и смены движка маршрутизация встаёт на паузу и потом возобновляется.
- WinDivert берётся из папки запущенного движка (`winws2.exe` — рядом с ним, `winws.exe` — `bin\WinDivert.dll`
  в папке zapret); ничего не запущено — Flowseal, затем zapret2. Своего драйвера хаб не ставит.
- Пока маршрутизация включена, хаб держит драйвер WinDivert загруженным. Поэтому системная проверка
  «осиротевший драйвер WinDivert» показывается пройденной, а «Удалить службу» и «Удалить службы» (удаление
  драйвера) на время своей работы ставят маршрутизацию на паузу.
- Однажды включённая маршрутизация держит `WinDivert.dll` движка загруженной (файл занят), пока хаб не закрыт.
  Чтобы распаковать обновление Flowseal или zapret2 поверх папки, закройте хаб.
- Трафик самого хаба и процесса, слушающего порт прокси, не перехватывается (защита от петли через VPN).

Команды CLI: `router on|off|status`, `routes list|show|add|edit|enable|disable|remove|preset|flows`, см.
`docs/cli.md`.

## Командная строка для агентов

`zapret-hub-cli.exe` лежит рядом с `zapret-hub.exe` и передаёт команды работающему приложению: ИИ-агент
(Claude Code и другие) или скрипт смотрит состояние, применяет стратегии, меняет списки и флаги, запускает тесты
и читает рейтинг. Вывод — JSON, коды выхода постоянные, прав администратора CLI не просит.

По умолчанию CLI выключен: включите «Управление из командной строки» в настройках. После этого любая
программа, запущенная от вашего имени, сможет менять zapret через приложение, а со zapret2 запускать код от
администратора и SYSTEM (см. раздел «Как включить» в `docs/cli.md`). Проверка: `zapret-hub-cli status`.

Подобрать и применить лучшую стратегию:

```
zapret-hub-cli tests run --wait
zapret-hub-cli apply-best
zapret-hub-cli quick-check
```

Все команды, коды выхода и рецепты — в `cli.md` рядом с exe (в исходниках — `docs/cli.md`) и в
`zapret-hub-cli --help`.

## Антивирусы

Приложение запускает `winws.exe` и `winws2.exe`, управляет службами zapret и zapret2 и может править `hosts`, поэтому антивирус может счесть
его подозрительным. Своего WinDivert в приложении нет: драйвер берётся из папки zapret. Если exe попал в
карантин, добавьте папку приложения в исключения.

## Если что-то не работает

Текст любой ошибки копируется кнопкой «Копировать» в уведомлении; подробности — в журнале `data\logs`.
Системные проверки на вкладке Zapret повторяют диагностику `service.bat`.

## Удаление

1. Выключите автозапуск в настройках (или `schtasks /Delete /TN "Zapret Hub" /F`).
2. Выйдите из приложения через трей и удалите его папку.
3. По желанию удалите ключ уведомлений: `reg delete HKCU\Software\Classes\AppUserModelId\ZapretHub /f`.

Служба zapret или zapret2 и папки Flowseal и zapret2 остаются. Службу удаляет кнопка на вкладке Zapret
(службу `zapret` — и `service.bat`).

Остаются и файлы `general (HUB <имя>).bat` в папке zapret (удалите их вручную), блок между
`# zapret-hub begin` и `# zapret-hub end` в `C:\Windows\System32\drivers\etc\hosts` (удаляется в редакторе,
запущенном от администратора) вместе с копией `hosts.zapret-hub.bak` и настройка TCP timestamps (см. выше).

## Сборка из исходников

Нужны Rust (версию задаёт `rust-toolchain.toml`), Node.js 24 LTS и Microsoft C++ Build Tools.

```
npm install
npm run tauri build
```

Готовый exe — `target\release\zapret-hub.exe`. CLI — отдельный пакет: `cargo build --release -p cli` собирает
`target\release\zapret-hub-cli.exe`. `npm run tauri dev` запускается из терминала с правами
администратора; сборка, тесты, `npm run check` и `zapret-hub-cli` — из обычного.

Выпуск: поднять версию в `Cargo.toml` и `package.json`, раздел версии в `CHANGELOG.md`, затем тег `v<версия>`
(`git tag v0.7.0 && git push origin v0.7.0`). CI (`.github/workflows/release.yml`) прогоняет тесты, собирает zip
и создаёт релиз с этим разделом CHANGELOG. Ручной запуск в Actions только собирает zip (артефакт).

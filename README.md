# Zapret Hub for Linux

Нативный графический интерфейс (GUI) и утилита командной строки (CLI) для обхода замедлений и блокировок DPI на базе **zapret2** (`nfqws2`), **nftables**, гибкой **SOCKS5-маршрутизации** и **tg-ws-proxy-rs**. Разработано на базе **Tauri v2**, **Rust** и **Svelte 5**.

---

## Ключевые возможности

### 1. Движок zapret2 (nfqws2) и стратегии
* **24 встроенные стратегии**: универсальные стратегии на базе Lua-скриптов (`general`, `general-sni`, `ALT1`–`ALT13`, `EXP`, `FAKE TLS AUTO`, `SIMPLE FAKE`), адаптированные для работы в среде Linux.
* **Игровые профили**: автоматическое расширение диапазонов портов для голосовой связи Discord (UDP `50000-65535`) и игровых сервисов.
* **Оркестратор circular**: динамическая ротация вариантов десинхронизации per-domain — при обнаружении сбросов (RST) или ретрансмиссий движок автоматически перебирает профили и запоминает рабочий вариант.
* **Встроенный редактор и конструктор**: создание пользовательских стратегий с интерактивной проверкой синтаксиса и сухим прогоном (`nfqws2 --dry-run`).

### 2. Управление трафиком через nftables (`inet zapret_hub`)
* **Автоматическая настройка правил**: создание и очистка таблицы `inet zapret_hub` с очередями `NFQUEUE` (по умолчанию `num 200 bypass`).
* **Защита от бесконечного цикла**: трафик локального интерфейса `lo` и служебные пакеты с `fwmark 0x40000000` исключаются из очереди.
* **Группа обхода `zapret-bypass`**: любой процесс, запущенный в контексте группы `zapret-bypass` (например, через `sg zapret-bypass "<команда>"`), направляется в сеть напрямую в обход очередей nfqws2.
* **Исключения портов**: исключение локальных торрент-портов, SSH, WireGuard и OpenVPN из обработки DPI.

### 3. Интеграция с systemd
* **Изоляция привилегий (Drop Root)**: служба `zapret2.service` запускается с минимально необходимым набором привилегий ядра Linux:
  ```ini
  AmbientCapabilities=CAP_NET_ADMIN CAP_NET_RAW
  CapabilityBoundingSet=CAP_NET_ADMIN CAP_NET_RAW
  ```
* **Автовосстановление и автозапуск**: перезапуск службы при сбоях и старт при загрузке системы.
* **Просмотр логов в реальном времени**: встроенный монитор журнала `journald` прямо во вкладке инструментов хаба.

### 4. Встроенный Telegram WebSocket Proxy (`tg-ws-proxy-rs`)
* Автоматическая загрузка легковесного бинарного прокси-демона [valnesfjord/tg-ws-proxy-rs](https://github.com/valnesfjord/tg-ws-proxy-rs).
* Обход блокировок протокола MTProto путём туннелирования трафика Telegram через защищённый WebSocket (TLS) на порт 443.
* Запуск без прав суперпользователя под управлением пользовательской службы `systemd --user` (`zapret-hub-tg-ws`).
* Включение и генерация ссылки подключения в один клик в GUI или через CLI.

### 5. Маршрутизация SOCKS5 и списки исключений
* **Перенаправление по правилам**: маршрутизация TCP/UDP-трафика в локальный SOCKS5-прокси (Xray, Sing-box, NekoBox) по:
  * Доменным маскам (`discord.com`, `twitch.tv`).
  * IPv4/CIDR подсетям.
  * Именами Linux-процессов (`telegram-desktop`, `discord`, `firefox`).
* **Определение владельцев сокетов**: парсинг `/proc/net/tcp` и файловых дескрипторов `/proc/<pid>/fd/` для точной идентификации процессов.
* **Пресеты правил**: готовые конфигурации для Discord, Cloudflare, Telegram, Twitch.
* **Исключения прямого трафика**: встроенные правила обхода для российских банков, Госуслуг и локальных подсетей (`10.0.0.0/8`, `192.168.0.0/16`, `172.16.0.0/12`).

### 6. Быстрое тестирование и автоподбор стратегий
* Высокоскоростной параллельный чекер доступности сайтов через нативные сокеты и `curl` (замеры HTTP, TLS 1.2, TLS 1.3, ICMP Ping).
* Быстрое отсечение тайм-аутов при детекции блокировок DPI (TCP RST, TLS handshake freeze).
* Автоматическая очистка истории тестов (сохранение последних 50 прогонов).
* Применение лучшей стратегии в один клик на основе рейтинга задержки и доступности.

### 7. CLI и средства самодиагностики для ИИ-агентов
Утилита `zapret-hub-cli` общается с приложением через защищённый Unix Domain Socket (`$XDG_RUNTIME_DIR/zapret-hub.sock`) с правами `0600`:
* Поддержка формата `--json` для автоматизации и интеграции со скриптами или LLM-агентами.
* **`doctor`**: комплексная проверка состояния системы (наличие `nfqws2`, загрузка модулей ядра `nfnetlink_queue` и `nft_queue`, статус `systemd`, права capabilities, правила nftables).
* **`probe <domain>`**: детальная диагностика типа блокировки конкретного домена (HTTP 451 / перенаправление / TCP RST / сброс хэндшейка).

## Архитектура проекта

```
zapret-hub/
├── crates/
│   ├── cli/       # zapret-hub-cli: консольная утилита и IPC через Unix Domain Socket
│   ├── exec/      # Управление процессами Linux (setpgid, POSIX сигналы, UTF-8 потоки)
│   ├── probe/     # Сетевые замеры (curl, ping, socks5 handshake, классификация DPI)
│   ├── router/    # Маршрутизатор трафика, парсер /proc/net/tcp, таблицы правил
│   ├── tester/    # Каталог стратегий, запуск тестов, скоринг и ротация истории
│   ├── zapret/    # Корневые операции Linux (root.rs, pkexec/sudo, DNS-сброс)
│   └── zapret2/   # Интеграция с nfqws2, генерация nftables (nft.rs), systemd unit
├── frontend/      # Интерфейс на Svelte 5 (Runes), TailwindCSS и Vite
└── src-tauri/     # Бэкенд Tauri v2, подсистемы tg-ws-proxy, doctor/probe, tray
```

## Установка и сборка (CachyOS / Arch Linux)

### 1. Системные зависимости

Установите необходимые пакеты через `pacman`:

```bash
sudo pacman -S --needed \
    base-devel \
    git \
    curl \
    iputils \
    rust \
    cargo \
    nodejs \
    npm \
    webkit2gtk-4.1 \
    gtk3 \
    libayatana-appindicator \
    openssl \
    nftables \
    libnetfilter_queue \
    libnfnetlink \
    polkit
```

### 2. Настройка прав пользователя

Для запуска программ в обход перехвата создайте группу `zapret-bypass` и добавьте своего пользователя:

```bash
sudo groupadd -f zapret-bypass
sudo usermod -aG zapret-bypass $USER
```
*(После добавления группы перезайдите в сессию пользователя).*

Для выполнения команд управления `nftables` и системной службой `zapret2.service` без пароля через `sudo -n`, добавьте правило в `/etc/sudoers.d/zapret-hub`:

```bash
echo "$USER ALL=(ALL) NOPASSWD: /usr/bin/nft, /usr/bin/systemctl" | sudo tee /etc/sudoers.d/zapret-hub
sudo chmod 0440 /etc/sudoers.d/zapret-hub
```

### 3. Сборка проекта

Клонируйте репозиторий и соберите фронтенд и бинарные файлы:

```bash
# 1. Установка зависимостей фронтенда
npm install

# 2. Сборка фронтенда
npm run build

# 3. Сборка графического приложения и CLI
cargo build --release -p zapret-hub -p cli
```

Бинарные файлы будут скомпилированы в директорию `target/release/`:
* `target/release/zapret-hub` — графическое приложение;
* `target/release/zapret-hub-cli` — консольная утилита управления.

## Быстрый старт

1. Запустите графический интерфейс:
   ```bash
   ./target/release/zapret-hub
   ```
2. Мастер первого запуска поможет загрузить актуальный бинарник `nfqws2` и настроить начальную конфигурацию.
3. Во вкладке **«Тесты»** нажмите **«Запустить тестирование»**, чтобы проверить эффективность встроенных стратегий для вашего провайдера.
4. Выберите наиболее подходящую стратегию и нажмите **«Применить»**. Служба `zapret2.service` будет сгенерирована и активирована автоматически.

### Управление через CLI

```bash
# Проверить состояние системы и модулей ядра
zapret-hub-cli doctor

# Запустить тестирование стратегий с ожиданием результатов
zapret-hub-cli tests run --wait

# Применить лучшую стратегию по итогам тестирования
zapret-hub-cli apply-best

# Продиагностировать блокировку конкретного домена
zapret-hub-cli probe rutracker.org

# Управление Telegram WebSocket Proxy
zapret-hub-cli tg-ws status
zapret-hub-cli tg-ws start
```
